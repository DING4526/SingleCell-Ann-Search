# 生产发布阻断清单

以下事项不属于本轮 laptop 前端与资源生命周期改造，但在对外部署前必须全部关闭：

- 使用生产 WSGI 服务启动应用；禁止通过 Flask 开发服务器或 `debug=True` 对外提供服务。
- 通过部署环境注入高强度、唯一的 `SECRET_KEY`，不得使用仓库中的开发回退值。
- 首次部署时创建独立管理员并强制更换密码；删除或停用任何默认、演示账号。
- 配置并备份 `AI_CREDENTIAL_ENCRYPTION_KEY`；确认密钥、模型凭据和数据库文件不进入版本库或构建产物。
- 在真实反向代理与 HTTPS 环境中校验安全 Cookie、请求体大小、上传目录权限和受管文件根目录。
- 建立 SQLite 数据库与 `data/` 受管资源的同批次备份、恢复演练和 `artifact_cleanup` 失败告警。
- 以生产配置重新执行 `pytest -q`、`npm test -- --run`、`npm run typecheck`、`npm run build`，并完成一次空环境迁移与 `PRAGMA foreign_key_check`。

上述项目全部完成前，不应把课程演示或本地开发配置视为生产可发布配置。
