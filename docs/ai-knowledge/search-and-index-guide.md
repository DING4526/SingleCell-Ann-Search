# 检索与索引选择

## 单数据集检索

单数据集检索适合在一个数据集内寻找相似细胞。它要求查询数据集存在 ready/active 的 ANN 索引。Top-K 范围为 1 至 100，可以按 cell type 过滤。距离只在当前索引的向量空间和度量配置下解释。

## Fan-out 跨数据集检索

Fan-out 使用查询数据集的向量分别访问多个数据集的独立索引，再合并结果。目标索引必须与源索引具有兼容的向量维度和距离度量。独立训练或未经对齐的表达空间即使维度相同，也不应直接解释为严格可比的生物学距离。

## 联合索引检索

联合索引在多个数据集的公共基因上处理数据，并通过 Harmony 批次校正建立共享空间。它适合需要跨数据集统一排名和可视化的场景。查询数据集必须被该联合索引纳入，并且联合索引状态必须为 ready。

## 自动选择顺序

用户明确指定模式时优先采用，但后端仍会验证权限、归属和状态。只涉及一个数据集时默认使用单数据集检索。跨数据集请求优先使用覆盖目标数据集的 ready 联合索引；没有合适联合索引时才尝试兼容的 Fan-out。AI 不会自动构建、删除或替换索引。

## 索引实验与保留

索引实验室会使用同一批真实查询比较多个候选的 Recall、平均/P95 查询耗时、构建耗时和文件体积。实验完成后可以保留 1–3 个成功且 Recall 不低于 0.80 的候选：只保留一个适合追求简洁部署，保留多个适合兼顾召回、速度或不同检索策略。

“全部索引”展示当前数据集的 active、candidate、discarded 和异常记录。active/ready 索引可以直接进入 Query Lab；candidate 等待实验选优；discarded 记录只用于审计，物理文件通常已被清理。最终确认保留集合会退役并清理其它 active/candidate 文件，因此必须由用户明确确认。

## 研究限制

相似性表示当前预处理、嵌入、批次校正和索引参数下的邻近关系，不等同于细胞谱系、病理机制或临床因果关系。跨数据集比较必须同时报告空间兼容性、缺失数据集和元数据质量。
