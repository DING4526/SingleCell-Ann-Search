# AI 助手

## 能做什么

AI 助手位于所有登录后页面，可结合当前路由、所选数据集、索引和任务状态回答平台使用问题。用户也可以进入“AI 助手”工作台查看完整会话。

## 页面导航

明确指令如“打开数据资源页面”或“进入当前数据集的检索实验室”会直接导航。仅询问“接下来去哪里”时，助手只提供建议按钮，不会突然切换页面。

导航只使用平台白名单路由和经过权限校验的资源 ID。助手不能生成任意网页地址、JavaScript 或 DOM 操作。

## 同一会话中的科学分析

涉及相似细胞、跨数据集检索或结果比较的问题会在当前会话自动切换到科学分析执行器，不再跳转另一套聊天页面。助手只展示数据集、查询细胞、结果数和检索范围等必要参数；用户确认后才执行 ANN。检索完成后默认显示简洁结论和关键统计，完整表格与图形可在 Query Lab 查看。

历史 AI 分析会话也会出现在统一会话列表中。旧 `/ai-analysis` 链接会转到 AI 助手工作台。

## 安全操作草案

助手可为数据处理、索引构建、索引实验、索引评估、联合索引、知识重建和个人知识笔记生成操作草案。

草案不是已经执行的任务。用户必须检查完整参数和影响并单独确认；后端会再次验证权限、资源状态和前置条件。草案十分钟后失效，重复确认不会创建重复任务。

确认后，助手会自动进入对应工作区，并在操作卡中持续显示后台 Task 的真实进度、结果和下一步。索引实验会直接打开本次实验，页面自动刷新候选构建与评估状态。涉及删除物理索引文件的最终选优仍需要用户在结果页再次确认。

助手不执行删除、权限变更、所有权转移、账号管理、模型配置或密钥操作。

## 页面上下文与隐私

助手只接收路由、筛选条件和经过验证的资源 ID，不读取密码、API Key、上传文件内容、未提交长文本或完整结果表。输入区会显示本轮使用的页面上下文，用户可以关闭。

## 回答语言与证据

默认回答使用简体中文。资源状态、权限和数字来自平台实时数据；知识资料只在后台用于补充回答。Evidence Key、RAG 片段和工具步骤不会出现在默认回答中，分析详情按需折叠查看。模型无法可靠通过校验时，平台返回中文确定性回答。
