# AI 与检索故障排查

## 模型无法启用

模型必须先完成连接测试。确认独立的 `AI_CREDENTIAL_ENCRYPTION_KEY` 已配置、API Key 有效、Base URL 正确且供应商已启用。聊天模型和 embedding 模型使用不同测试接口，聊天测试成功不代表 embedding 可用。

## 模型连接成功但没有内容

推理模型可能把较短的输出额度全部用于 reasoning content。平台会提高连接测试的输出额度并重试一次。仍无正文时，应检查模型 ID、思考模式和供应商控制台限额。

## 模型增强暂不可用

平台统计回答已经来自真实检索结果，可以继续使用。模型增强属于非阻塞步骤；超时、格式校验失败或引用无效时会终止增强并保留确定性回答，不会让 Run 持续计时。

## 知识文档没有语义索引

未配置 embedding、供应商不支持 embeddings 或向量重建失败时，文档状态可能显示 degraded。中文字符关键词检索仍然可用。管理员可以配置并测试 embedding 模型后重新索引。

## 跨数据集请求无法执行

检查目标数据集权限、源索引状态、向量维度和距离度量。联合检索还要求查询数据集已包含在 ready 联合索引中。AI 只使用现有 ready/active 索引，不会自动构建新索引。
